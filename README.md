# 💰 Family Expense Tracker

A simple and user-friendly **Family Expense Tracker** developed using Python. This project helps users manage and monitor family income and expenses in an organized way.

The application allows users to record family members, add income and expenses, and keep track of the overall financial balance.

## 📌 Project Overview

Managing expenses for a family can become difficult when there are multiple members, different sources of income, and regular daily expenses.

The **Family Expense Tracker** provides a simple solution by allowing users to maintain financial records in one place.

The main purpose of this project is to make expense management easier, more organized, and understandable.

## ✨ Features

* 👨‍👩‍👧‍👦 Add and manage family members
* 💵 Record income/earnings
* 💸 Add and track expenses
* 📊 Calculate total income
* 📉 Calculate total expenses
* 💰 Display remaining balance
* 🗂️ Organize financial information
* 🖥️ Simple and easy-to-use interface
* 🐍 Developed using Python

## ⚙️ How It Works

The basic working process of the application is:

```text
Start
  ↓
Add Family Members
  ↓
Enter Income
  ↓
Add Expenses
  ↓
Calculate Total Income
  ↓
Calculate Total Expenses
  ↓
Calculate Remaining Balance
  ↓
Display Financial Summary
  ↓
End
```

### 💡 Balance Calculation

The remaining balance is calculated using:

```text
Remaining Balance = Total Income - Total Expenses
```

For example:

```text
Total Income    = ₹50,000
Total Expenses  = ₹32,000

Remaining Balance = ₹50,000 - ₹32,000
                  = ₹18,000
```
